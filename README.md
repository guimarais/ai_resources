### More from Anthropic

* [Anthropic courses on GitHub](https://github.com/anthropics/courses) - notebook versions of the courses, runnable locally
* [Interactive prompt engineering tutorial](https://github.com/anthropics/prompt-eng-interactive-tutorial) - hands-on, chapter-by-chapter exercises
* [Anthropic Cookbook](https://github.com/anthropics/anthropic-cookbook) - working recipes for RAG, tool use, agents and more
* [Building effective agents](https://www.anthropic.com/engineering/building-effective-agents) - short essay on when (and when not) to build agents
* [Model Context Protocol](https://modelcontextprotocol.io) - open standard for connecting LLMs to tools and data

## AI Security

* [OWASP Top 10 for LLM Applications](https://genai.owasp.org) - the main risks to know when building with LLMs (prompt injection, data leakage, insecure output handling...)
* [MITRE ATLAS](https://atlas.mitre.org) - knowledge base of real-world attacks on AI systems, in the style of MITRE ATT&CK
* [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework) - reference framework for governing and managing AI risk
